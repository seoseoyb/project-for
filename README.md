1. 프로젝트 소개
프로젝트명: 행사 포스터 일정 자동 등록 시스템

본 프로젝트는 행사 포스터 이미지에 포함된 정보를 자동으로 인식하고, 추출한 행사 일정을 구글 캘린더에 등록할 수 있도록 제작한 웹 애플리케이션이다.

축제, 공연, 전시, 체험 행사 등 다양한 행사 정보를 확인할 때 포스터의 내용을 직접 읽고 일정을 기록해야 하는 번거로움을 줄이기 위해 개발하였다.

사용자가 포스터 이미지를 업로드하면 행사명, 날짜, 시간, 장소 등의 기본 정보와 초청 가수, 참가비, 주최·주관 등의 추가 정보를 자동으로 추출하여 정리해 준다. 또한 추출된 정보를 직접 수정할 수 있으며, 최종적으로 확인한 일정을 구글 캘린더에 등록할 수 있다.

이를 통해 포스터 확인부터 정보 정리, 일정 등록까지의 과정을 간편하게 처리하고 행사 일정을 효율적으로 관리할 수 있도록 하였다.

2. 사용법
1. 앱 접속: 웹 브라우저에서 행사 포스터 일정 자동 등록 시스템에 접속한다.
2. 포스터 업로드: 포스터 업로드 영역에서 분석하고 싶은 행사 포스터 이미지를 선택한다.
3. 정보 추출: 업로드한 포스터를 선택한 후 검색 버튼을 누르면 이미지에 포함된 문자를 인식하고 행사 정보를 자동으로 분석한다.
4. 결과 확인: 분석이 완료되면 포스터 이미지 옆에 추출된 행사 정보가 표시된다. 행사명, 날짜, 시간, 장소 등의 기본 정보와 추가 정보를 확인할 수 있다.
5. 정보 수정: 자동으로 추출된 내용이 실제 포스터와 다르거나 누락된 경우 정보 수정 기능을 이용하여 직접 수정한다.
6. 일정 등록: 모든 정보의 확인이 끝나면 구글 캘린더 등록 버튼을 눌러 해당 행사를 캘린더에 추가한다.
   
3. 주요 기능 설명
① 포스터 이미지 인식 기능
- 행사 포스터 이미지를 업로드하면 이미지 속 문자를 자동으로 인식한다.
- 한글과 영어가 혼합된 포스터도 분석할 수 있다.
- 여러 장의 포스터를 업로드하여 각각의 행사 정보를 추출할 수 있다.
② 행사 정보 자동 추출 기능
- 행사명, 개최 날짜, 시간, 장소 등 기본 정보를 자동으로 분류한다.
- 초청 가수 라인업, 주최·주관, 참가비, 참가 대상, 연령 제한, 참여 방법 등의 추가 정보도 추출한다.
- 캠핑, 공연, 체험, 플리마켓, 푸드 등 행사와 관련된 주요 특징을 파악한다.
③ 날짜 및 장소 구분 기능
- 행사 날짜와 신청 마감일을 구분하여 인식한다.
- 여러 날짜가 표시된 경우 행사 기간에 맞게 정보를 정리한다.
- 예매처나 주최 측 연락처 등이 실제 행사 장소로 잘못 분류되지 않도록 구분한다.
④ 정보 확인 및 수정 기능
- 추출된 정보와 원본 포스터를 함께 비교할 수 있다.
- 인식이 잘못된 정보는 사용자가 직접 수정할 수 있다.
- 날짜 후보가 여러 개일 경우 원하는 날짜를 선택할 수 있다.
⑤ 구글 캘린더 연동 기능
- 확인이 완료된 행사 정보를 구글 캘린더에 등록할 수 있다.
- 행사명, 날짜, 시간 등의 정보를 일정으로 저장한다.
- 동일한 일정의 중복 등록을 방지한다.
⑥ 사용자 친화적인 디자인
- 투명 테마와 마우스 효과 등 개성 있는 UI를 구성하였다.
- 행사 정보를 카드 형태로 구분하여 가독성과 사용 편의성을 높였다.
  
4. 실행 방법
1. 첫 화면 확인: 웹사이트에 접속하면 '오늘의 행사도 다이어리에 차곡차곡'이라는 제목과 포스터 업로드 영역이 있는 첫 화면이 나타난다.

2. 포스터 선택: 포스터 업로드 버튼을 눌러 컴퓨터에 저장된 행사 포스터 이미지를 선택한다. 선택한 포스터가 화면에 업로드된다.

3. 정보 검색 버튼 클릭: 포스터 선택을 완료한 후 화면에 표시된 고양이 얼굴 모양의 검색 버튼을 누른다. 버튼을 누르면 포스터의 내용을 분석하는 과정이 진행된다.

4. 분석 결과 확인: 분석이 완료되면 선택한 포스터 이미지와 함께 행사 정보 카드가 나타난다. 행사명, 날짜, 시간, 장소가 각각 구분되어 표시되며, 아래쪽에서는 추가 정보도 확인할 수 있다.

5. 정보 수정 버튼 이용: 추출된 정보 중 잘못된 부분이 있다면 정보 수정 기능을 눌러 내용을 변경한다. 수정이 필요한 항목을 직접 입력하거나 선택한 후 변경 사항을 반영한다.

6. 캘린더 등록 버튼 클릭: 최종적으로 확인한 행사 정보의 캘린더 등록 버튼을 누른다. 구글 캘린더 연동 과정을 거쳐 해당 일정이 등록된다.

7. 등록 일정 확인: 구글 캘린더에 접속하여 등록된 행사명과 날짜, 시간 등을 확인한다.
